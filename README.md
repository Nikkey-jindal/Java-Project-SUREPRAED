# Student Management System

## About the Project
The **Student Management System** is a simple Java-based application developed using Core Java, Strings, and Arrays. It helps manage student records through basic CRUD operations.

## Features
- **Add Student:** Add new student records.
- **Search Student:** Search for a student using available details.
- **Update Student:** Modify existing student information.
- **Delete Student:** Remove student records.
- **Display Student Records:** View stored student details.
- **Array-Based Data Storage:** Store and manage student information using arrays.

## Technologies Used
- **Java**
- **Core Java**
- **Strings**
- **Arrays**
